# Pranam Upagade — Portfolio

Personal portfolio for Pranam Manav Upagade, AI-driven Product Manager.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- lucide-react

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Editing content

All copy lives in [`data/content.ts`](./data/content.ts). Update experience, case studies, skills, and contact details there.

## Assets

- Portrait: `public/images/pranam.jpg`
- Resume: `public/resume.pdf` (replace the placeholder with your real PDF)
- Open Graph: `public/og.jpg`

## Deploy

Deploy on Vercel — no backend required.
